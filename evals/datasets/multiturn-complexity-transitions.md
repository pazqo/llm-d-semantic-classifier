# Multi-turn complexity transition set

`multiturn-complexity-transitions.jsonl` contains 160 tentative target turns:
10 examples for each ordered pair of complexity labels:

```text
SIMPLE, MEDIUM, COMPLEX, REASONING
```

The `previous_gold_tier` and `gold_tier` fields make transition analysis
explicit. The set is generated by:

```bash
python3 hack/generate-multiturn-transitions.py
```

Run it with:

```bash
cargo run --release --bin eval-multiturn -- \
  --model artifacts/models/complexity \
  --classifier classifiers/complexity.json \
  --dataset evals/datasets/multiturn-complexity-transitions.jsonl \
  --mode all \
  --json /tmp/multiturn-transitions-report.json
```

This is a transition-coverage and harness smoke-test set, not yet a valid
context-dependence benchmark. The current-turn wording intentionally signals
the target class (for example, `design`, `explain`, or `prove`), so current-only
classification can perform very well without using history. The next dataset
revision should make follow-up wording more ambiguous and require the history
to disambiguate the intended task.
